# Learning Writeback Overlay

Load this overlay only after a failure is shown to be novel, repeatable, and
paired with a concrete prevention rule or verification contract.

- Append one concise entry to the existing Learning Closure Matrix or structured
  learning ledger; do not create a parallel report.
- Routine command typos, transient environment noise, one-off tool failures,
  and already-covered lessons require no writeback.
- Create or update an ADR only for a durable cross-module architectural choice
  with alternatives and consequences.
- Record the phenomenon, root cause, prevention rule, and verification surface.
  Do not turn an unverified hypothesis into a lesson or authority change.
