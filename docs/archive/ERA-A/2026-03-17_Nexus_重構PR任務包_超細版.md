# 2026-03-17 Nexus 重構 PR 任務包（超細版，TDD 版）

## TDD 全域規範（所有 PR 必須遵守）
1. `RED`: 先寫失敗測試，不得先改實作。
2. `GREEN`: 只寫最小實作讓測試通過，不做順手重構。
3. `REFACTOR`: 在綠燈下重構，並保持測試全綠。
4. 每個 PR 必須附：
- Red 測試輸出（失敗）
- Green 測試輸出（通過）
- Refactor 後回歸輸出

## PR 通用驗收
- `uv run pytest -q`
- `uv run scripts/nexus_cli.py nexus:benchmark --tasks 10 --output ci_benchmark.csv`
- success rate >= 95%
- max drift < 0.5
