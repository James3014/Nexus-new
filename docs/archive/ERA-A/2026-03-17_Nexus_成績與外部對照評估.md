# 2026-03-17 Nexus 成績與外部對照評估

## 結論摘要
- 目前成績：**工程治理強、解題競技力待補強**。
- 建議分級：
  - **治理成熟度：A-**
  - **對外競技力（benchmark 可比）：B- ~ B**

## 目前已具備的優勢
1. 流程治理完整（P-D-R-A-C）。
2. 可回放、可審核、可清理（replay / gate / clean）。
3. CI Gate 與 regression 基礎已建立並可重跑。

## 目前主要缺口
1. TRU-101 尚未完成對標：集成環境 tokens 仍為 0。
2. 尚未形成可對外直接比較的「解題率/成本/時間」穩定報表。

## 與可見公開專案的相對位置（2025-2026 生態）
- 公開 benchmark（如 SWE-bench 生態）常見宣告區間約 **45%~80%+**（依榜單與設定差異大，且含廠商自報）。
- Nexus 現階段更像 **Governance Runtime / Control Plane**，不是純粹追求解題率的代理。
- 因此定位上：
  - 在「治理可追溯」面向可競爭。
  - 在「公開解題率」面向仍需補硬指標。

## 升級到下一級的必要條件
1. 打通真實 token 歸集（非零、可持續重現）。
2. 完成 10-case 全量 replay 穩定報告（成功率、平均耗時、drift、health）。
3. 補一份對外可比基準結果（同一設定、同一資料集、可重跑）。

## 判定語句（對外建議）
- **Stable（治理面）+ TRU-101 Pending（數據面）**。
- 避免使用「100% finalized」措辭，直到 token 真實歸集鏈路完成。
