### 1. 舊收據缺指標回歸 (Legacy Receipt Completeness)
- **案例來源**: `BackfillService.migrate_receipt`
- **風險**: v27 舊數據缺失 Token 統計，可能被誤判為 `PASS`。
- **守護規則**: 缺失指標必須物理標記為 `BACKFILL_NEEDED`，嚴禁晉升 `claimable`。
- **測試點**: `TestV28SmokeAndRegression.test_regression_old_receipt_missing_telemetry`

### 2. Memory 錯誤命中過濾 (Retrieval Denoising)
- **案例來源**: `MemoryRetrievalService.rank_and_pack`
- **風險**: 語義相似但因果無關的記憶（Relevance < 0.7）污染決策上下文。
- **守護規則**: 低相關性命中必須被物理過濾，Neutral Archive 命中不得觸發 `is_actionable`。
- **測試點**: `TestV28SmokeAndRegression.test_regression_memory_false_hit_pollution`

### 3. 狀態版本漂移阻斷 (State Version Drift)
- **案例來源**: `TaskStateStore.reject_if_stale`
- **風險**: 長流程中舊版本 Agent 覆蓋新版本狀態。
- **守護規則**: 寫入時必須執行 `base_version` 比對，偵測到 Stale Update 即物理拋出異常。
- **測試點**: `TestV28SmokeAndRegression.test_regression_stale_state_drift`

### 4. 跨模組判決不變性 (Cross-Module Invariant)
- **案例來源**: `GateJudge.decide`
- **風險**: Memory 的檢索波動意外改動了 Gate 的 Allowed 判斷。
- **守護規則**: `decide` 是只讀傳入 Facts 的純函數，不應受 Memory Pack 內容影響判決結果。
- **測試點**: `test_memory_volatility_does_not_affect_gate_verdict`
