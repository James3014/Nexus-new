# 🛡️ Nexus Quantum Oracle v0.6 Spec

## 量子決策循環 (E-S-R-D)
1. **ENCODE**: 信念單點真相 -> Dirichlet 概率分佈。
2. **SIMULATE**: MCTS 模擬 Top-N 宇宙路徑。
3. **RANK**: MUSE Oracle 評估各宇宙 Expected Value (EV)。
4. **DECIDE**: 執行 EV 最高路徑，同步對沖 (Hedge) 次優宇宙。

## 關鍵指標
- **UNCERTAINTY_COVERAGE**: 覆蓋的邊緣場景百分比。
- **EXPECTED_VALUE_LIFT**: 量子決策相較單點決策的效能提升。
