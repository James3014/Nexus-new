# Nexus v27.6 Operationally Hardened Governance Platform Plan

本計畫旨在將 Nexus 轉化為可長期運營的平台，強化 Ownership、風險分級、全鏈路 Trace 與 Lifecycle 管理。

---

## 🎯 十大里程碑 (Milestones)

- [ ] **M1. Ownership 與 Risk Tier 固化**: 建立 `owner_map` 與 `risk_tier` 模型。
- [ ] **M2. End-to-End Problem Trace**: 實作從 Ingress 到 Freeze 的決策鏈追蹤。
- [ ] **M3. Policy Profile 細化**: 擴充政策需求與環境保護規則。
- [ ] **M4. Runtime Guardrails**: 實作執行期的 Write-scope 與 Readonly 防線。
- [ ] **M5. Evals 內建化**: 建立分類準確度與政策回歸的 Eval Suite。
- [ ] **M6. Observability 升級**: 導入治理級 Telemetry 指標。
- [ ] **M7. Lifecycle 管理**: 實作 Sandbox 與 Flag 的自動過期與清理。
- [ ] **M8. Release Governance 強化**: 讓 Canary/Rollback 與風險等級掛鉤。
- [ ] **M9. 專用 Lane 優化**: 提升 Review 與 Refactor 為一等公民車道。
- [ ] **M10. v27.6 Freeze**: 產出最終運營基線指紋。
