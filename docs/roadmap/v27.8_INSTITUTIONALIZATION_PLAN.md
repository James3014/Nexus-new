# Nexus v27.8 治理制度化與長期運營計畫 (Institutionalization Plan)

## 📌 戰略定調
v27.7 已經在物理層面證明了「小核心、強邊界、高韌性」的架構誠信。
**v27.8 的使命是將這些「一次性驗證」轉化為「長期、自動、不可逾越的制度」。**

---

## 🎯 四大制度化支柱 (Core Pillars)

### M1. CI 級架構健身閘門 (Fitness in CI)
*   **目標**: 將 `check_architecture_fitness.py` 整合進 CI 流程。
*   **關鍵規則**: 任何導致 Dependency Direction 違規或模組過大 (Oversized) 的 Commit 將直接被 Block。
*   **實施**: 實作 `nexus/ci/fitness_gate.py`。

### M2. 週期化混沌演練 (Periodic Chaos Drills)
*   **目標**: 將韌性演練從「發佈前跑一次」提升為「定期自動化執行」。
*   **關鍵場景**: 模擬 Policy Engine 延遲、Registry 故障與 Trace Sink 斷線。
*   **實施**: 建立 `scripts/ops/run_weekly_resilience_drill.sh`。

### M3. 全域跨族群回歸集 (Unified Regression Suite)
*   **目標**: 建立橫跨 Django, Astropy, Concurrency 的「全明星」驗收集。
*   **關鍵功能**: 驗證 Policy Version 升級後，舊有所有家族的 Acceptance 仍能維持 100%。
*   **實施**: 實作 `tests/regression/test_cross_family_acceptance.py`。

### M4. 端到端可審計鏈路 (Auditable Integrity Chain)
*   **目標**: 串聯 `Freeze Manifest` + `Trace Log` + `Replay Index`。
*   **關鍵功能**: 一鍵產出任何任務從 Ingress 到 Final Release 的完整誠信證明。
*   **實施**: 實作 `nexus/evidence/audit_chain_generator.py`。
