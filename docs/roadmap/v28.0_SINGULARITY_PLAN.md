# Nexus v28.0 治理奇點計畫 (Governance Singularity Plan)

## 📌 戰略定調
v27.9 實現了治理能力的「閉環」。
**v28.0 的使命是將閉環機制昇華為「統一語言」，達成系統的元治理 (Meta-Governance) 與自穩定。**

---

## 🎯 四大奇點里程碑 (Singularity Milestones)

### M1. 統一決策語言 (Unified Decision Language, UDL)
*   **目標**: 將多維指標（Policy, SLO, Fitness, Drill）歸一化為單一決策向量。
*   **關鍵功能**: 實作 `nexus/governance/udl_engine.py`，產出 `GovernanceHealthScore` (0.0 - 1.0)。
*   **效益**: 消滅不同模組間的「指標方言」，實現統一的治理語義。

### M2. 可預測調節與自穩定 (Predictable Adjustments)
*   **目標**: 讓系統的調節動作 (如降級、縮減放量) 具備確定性。
*   **關鍵功能**: 自動調節動作必須記錄為 `AdjustmentReceipt`，且支援 Replay 驗證「為什麼在當時必須收緊政策」。
*   **實施**: 擴充 `nexus/ops/adjustment_handler.py`。

### M3. 治理發佈火車 (Governance Release Train)
*   **目標**: 將分層回歸與誠信鏈路標準化為不可更動的週期。
*   **關鍵功能**: 建立 `release_train.sh`，強制串聯：`Core Regression -> Chaos Drill -> Audit Chain Generation -> Sealing`。
*   **實施**: 整合 T1-T9 產出的所有制度化工具。

### M4. 閉環失效監控 (Loop-Back Monitoring)
*   **目標**: 監控「監控者」，偵測治理迴路本身的故障。
*   **關鍵功能**: 偵測 Policy Engine 與 SLO Manager 之間的信號漂移。若閉環發生正回饋振盪（異常收緊或異常放寬），立即觸發 **Safety Halt**。
*   **實施**: 實作 `nexus/governance/loop_monitor.py`。
