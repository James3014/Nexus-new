# P0.1c Runner-Level Abort Receipt Coverage

## Root Cause

`swe_local_heal.py::main()` has two exception paths that write to JSONL but **never write abort receipts**:

1. `ensure_workspace_state()` failure (line 564-576) — workspace setup before pipeline
2. `pipeline.run()` critical exception (line 658-669) — any failure during pipeline execution

This means if astropy-12907 fails at workspace provisioning, no abort receipt is produced — violating "If run starts, receipt must exist."

## Fix

Added `_write_runner_abort_receipt()` helper in `swe_local_heal.py`:
- Called in `ensure_workspace_state()` exception handler (failure_class="workspace_provisioning")
- Called in `pipeline.run()` exception handler (failure_class="runner_setup_failure")
- Both paths now write abort receipt BEFORE writing JSONL row

Also added `_map_workspace_subclass()` to classify workspace errors.

## Claim Boundary Fix

Updated `build_summary_header()` to use receipt coverage:
- `receipt_present_count` / `receipt_expected_count`
- `receipt_present_all` = count == expected
- `receipt_coverage` = "2/2" or "1/2"
- `public_claim_allowed=false` when receipt_present_all=false
