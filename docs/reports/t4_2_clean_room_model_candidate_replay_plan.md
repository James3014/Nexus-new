## 4. Workspace Reset Process

1. `git -C <workspace> checkout -- .`
2. `git -C <workspace> clean -fd`
3. Verify `git -C <workspace> status` shows clean
4. Record `git -C <workspace> rev-parse HEAD`

## 5. Source Hash Validation

For each candidate:
1. Read target file
2. Compute content hash
3. Compare with `source_snapshot_hash` from registry
4. If mismatch: mark `source_stale`, do not proceed to model replay

## 6. Canonical SEARCH Validation

For each candidate:
1. Search for buggy_line / buggy_block in source
2. Verify exact match count = 1
3. If 0 matches: mark `canonical_search_not_in_current_source`
4. If >1 matches: mark `ambiguous_canonical_search`, apply disambiguation
