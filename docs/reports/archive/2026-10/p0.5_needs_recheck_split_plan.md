## Target Files

### 1. `nexus/experimental/c6bd_preimage_retry.py` (new)

Shared module for C6BD pre-image retry logic used by both `isolated_workspace_apply.py` and `local_model_executor.py`.

**Extracted code:**
- The git log / git show / retry logic from `isolated_workspace_apply.py:110-164`
- The git pre-image fallback from `local_model_executor.py:175-201`

**Public API:**
```python
def run_c6bd_preimage_retry(
    *,
    source_root: str,
    target_file: str,
    search_text: str,
    tmpdir: str,
    patch_file: str,
    selected_candidate_hash: str,
    task_id: str,
) -> "IsolatedApplyReceipt | None":
    """Attempt C6BD pre-image retry. Returns receipt on success, None if retry not applicable."""

def resolve_anchor_from_preimage(
    *,
    repo_root: str,
    target_file: str,
    search_text: str,
    current_anchor: int,
) -> int:
    """Return a better anchor line from git pre-image history, or current_anchor when no better match exists."""
```

**Boundary:**
- This module remains under `nexus/experimental/` for P0.5 and P1.
- Its API is provisional; no mainline module may import it at module top-level.
- Promotion out of `experimental/` requires a later mainline review after P1-P2 prove the retry path is still needed.
