# ADR 0009: 策略晉升門檻與資料資產版本化

## 狀態
已接受 (Accepted)

## 背景
在 v26.9 階段，我們證明了定向修復 (Targeted Recovery) 的可行性。為了防止這種「定向優化」演變成「過度擬合」，我們需要嚴格的晉升門檻。

## 決策
1. **晉升公式**: 晉升必須滿足 `Gain(Challenge) > 0` 且 `Loss(Baseline) == 0`。
2. **Policy Table 版本化**: 將 `RetryPolicy.STRATEGY_MAP` 定義為獨立的資料資產，每次更新必須附帶對比實驗數據。
3. **物理證據**: 晉升提交必須包含 `ChallengeHarness` 的 100% 收斂收據。

## 後果
- **優點**: 
  - 確保了系統能力上限的真實提升，而非隨機波動。
  - 保護了 110 題穩態資產的絕對安全。
- **缺點**: 
  - 需要頻繁維護失敗地圖 (Failure Map)。
