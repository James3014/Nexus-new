# ADR 0006: 評測雙車道制 (Baseline vs Challenge)

## 狀態
已接受 (Accepted)

## 背景
全量 113 題的回放會掩蓋特定「極難題」的進展。若混合所有題目，難以判斷新改動是改善了穩定性還是提升了上限。

## 決策
將評測分為兩條車道：
1. **Baseline Lane**: 守成。針對 100 題已知穩定集進行回歸測試。
2. **Challenge Lane**: 攻堅。針對 13 題極難題、棄權題與新領域題進行壓測。

## 後果
- **優點**: 
  - 實驗指標更精準。
  - 避免「幸運抽樣」導致的分數虛高。
- **缺點**: 
  - 需要維護兩套不同的回放配置。
