# ADR 0011: 自動化晉升政策 (Auto-Promotion Policy)

## 狀態
草案 (Draft)

## 背景
Nexus v27 已確立了物理閘門，但晉升決策仍存在人工介入點。為了實現「治理一類系統」的目標，必須將晉升決策機器化。

## 決策
實施具備「Fail-Closed」特性的自動化晉升政策：
1. **硬門檻**: `Gain(Challenge) > 0` 且 `Loss(Baseline) == 0`。
2. **自動化分層**: 
    - **完全自動**: 符合核心指標且無漂移。
    - **需審計**: 淨增益大於 20% 但存在邊緣警告。
    - **禁止晉升**: 任何基線退化 (Regression)。
3. **失敗回退**: 任何步驟失敗必須產生 `RejectionReceipt` 並回滾 Manifest。

## 後果
- **優點**: 消除人工瓶頸，加速跨域收斂。
- **缺點**: 規則過於僵化可能導致某些具備潛力但有微小副作用的策略被誤殺。
