# ADR 0013: 漂移中止閘門 (Drift Stop Gate)

## 狀態
草案 (Draft)

## 背景
自動化晉升最怕「帶著漂移的規格晉升」，這會導致治理規格與實體程式碼脫鉤。

## 決策
實施「Drift-aware Auto-stop」機制：
1. **雜湊檢查**: 任何晉升前，必須驗證當前實體 `LocalHealTaskSpec` 的雜湊與簽署收據中的 `manifest_hash` 完全一致。
2. **零容忍漂移**: 只要 `PolicyDiff` 偵測到任何未經 ADR 核准的欄位變動，立即中止晉升流程。
3. **Fail-Closed 狀態**: 發生漂移時，鎖定晉升入口，直到 `DriftReporter` 產出對位報告且人工介入重置。

## 後果
- **優點**: 防止無聲漂移污染治理鏈。
- **缺點**: 可能在開發頻繁期導致 CI 頻繁阻斷。
