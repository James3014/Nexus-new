# Gemini CLI Bootstrap

1. Resolve `AGENTS.md` and `MUSE_PROTO.md` from the current worktree, then classify the execution lane.
2. Freeze the current worktree root, branch, HEAD, and dirty state before mutation.
3. An explicit Owner-authorized bounded `DIRECT_CANONICAL` change does not require a Task Card or lifecycle state.
4. Governed work resolves the active Git-tracked Task Card and uses formal lifecycle state and receipts for recovery; do not require an external sync command or a fixed checkout path.
5. A missing or stale Task Card blocks governed work, not eligible direct work.
