## 🏟️ Overview | 概覽

Nexus is a high-performance governance and orchestration layer for autonomous AI development. It provides a machine-verifiable audit trail and self-healing execution pipelines to ensure mission-critical reliability. By wrapping standard LLMs in a modular battlesuit of skills and gates, Nexus transforms raw model output into production-grade software engineering.

**[EN]** Nexus is the first autonomic AI development interface. It doesn't just execute loops; it learns from every execution trace to optimize its own decision weights and provides transparent fallback chains for mission-critical reliability.

**[ZH]** Nexus 是首個具備「自主演進」能力的 AI 開發介面。它不再只是單純執行循環，而是能從每一次的執行軌跡中學習，自動優化自身的決策權重，並為關鍵任務提供透明的備援鏈，確保極致的可靠性。

## 🏆 Key Features | 核心特性

*   **💎 Crystal Experience Crystallization**: Active learning from `tracelog.jsonl` to optimize router weights automatically.
*   **🚀 Fallback Resilience Chain**: Automatic switch to Top-K candidates if the primary skill fails.
*   **P-X-D-R-A-C Lifecycle**: Formalized autonomic state machine for zero-drift development (Plan-Execute-Diagnose-Research-Audit-Crystallize).
*   **FlashJudge 8.0**: Higher fidelity gate with semantic drift detection.
*   **Stadium Explorer**: Real-time telemetry for skill hit rates and autonomic adjustments.
*   **🌙 Night Shift Code Factory**: Fully integrated autonomic production line with governance auto-stop.
*   **🛡️ 19-Layer Governance**: Permanent L0 Rules & L1 Index for cross-turn state persistence.

## 🚀 Quick Start | 快速上手

```bash
# Fix a bug with Autonomic Precision
python3 scripts/engine/nexus_cli.py nexus run --task "fix hydration error on dynamic routes" --delivery-mode ask --silent

# Build a feature with top-tier resilience
python3 scripts/engine/nexus_cli.py nexus run --task "migrate session storage to redis" --domain "infra"
```

**[ZH]** Nexus 現在已在 `bug`、`feature`、`runner` 三條任務流接上交付門。使用 `--delivery-mode ask`，系統會在任務開始時主動詢問操作者，是否要啟用高標交付。

```bash
# 主動詢問這次 bug 修復是否需要高標交付
python3 scripts/engine/nexus_cli.py nexus run \
  --task "fix login callback regression" \
  --delivery-mode ask
```

更多規則請見 [`docs/DELIVERY_CONTRACT_CN.md`](docs/DELIVERY_CONTRACT_CN.md)。
