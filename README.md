# Nexus v28.3.0 Autonomic Governance

Nexus is a high-performance orchestration layer for autonomous AI development. It wraps Large Language Models in a machine-verifiable audit trail and self-healing execution pipelines to ensure engineering reliability.

## 🏟️ Overview

Unlike traditional AI coding tools that focus only on code generation, Nexus manages the full **P-X-D-R-A-C** lifecycle (Plan, Execute, Diagnose, Research, Audit, Crystallize). It provides:

- **Machine-Verifiable Audit Trails**: Every decision and tool call is recorded with cryptographic-grade evidence.
- **Self-Healing Pipelines**: Automatic diagnosis and repair of execution failures.
- **Policy-Based Governance**: 19 layers of gates to prevent regressions and enforce project standards.

## 🚀 Quick Start

```bash
# Verify system status
python3 scripts/engine/nexus_cli.py status

# Execute a task with autonomic governance
python3 scripts/engine/nexus_cli.py run --task "fix dynamic routing hydration error"
```

Current Maturity: **Beta (v28.3.0)**. Suitable for enterprise engineering teams requiring high-integrity AI automation.

## 🚀 Quick Start | 快速上手

```bash
# Fix a bug with Autonomic Precision
python3 scripts/engine/nexus_cli.py nexus run --task "fix hydration error on dynamic routes" --delivery-mode ask --silent

# Build a feature with top-tier resilience
python3 scripts/engine/nexus_cli.py nexus run --task "migrate session storage to redis" --domain "infra"
```

**[ZH]** Nexus 現在已在 `bug`、`feature`、`runner` 三條任務流接上交付門。使用 `--delivery-mode ask`，系統會在任務開始時主動詢問操作者，是否要啟用高標交付。

```bash
# 主動詢問這次 bug 修復是否需要高標交付
python3 scripts/engine/nexus_cli.py nexus run \
  --task "fix login callback regression" \
  --delivery-mode ask
```

更多規則請見 [`docs/DELIVERY_CONTRACT_CN.md`](docs/DELIVERY_CONTRACT_CN.md)。
