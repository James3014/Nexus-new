# Suggested Commands for Nexus v7

- **Run Nexus [task](../../task.md)**: `python3 scripts/nexus_cli.py nexus:bug --[task](../../task.md) "your [task](../../task.md)"`
- **Monitor Stats**: Check the WarRoom dashboard (if local server running) or `benchmark_report.json`.
- **Dry Run**: Use the `--dry-run` flag to simulate planning without execution.
- **Isolated Run**: Use `--output-dir ./temp_run` for CI/CD or parallel safety.
- **Cognitive Loop Audit**: `codex-loop --mode developer --apply`
