# OpenClaw bootstrap overlay

1. Read the current worktree's `AGENTS.md` and `MUSE_PROTO.md`.
2. Classify the execution lane before acting. An explicit Owner-authorized bounded `DIRECT_CANONICAL` change does not require a Task Card or lifecycle state.
3. For governed work, resolve the active Git-tracked Task Card and use lifecycle receipts with the current worktree identity for continuity; do not depend on a legacy state file or sync command.
